# Refri-Dev 🥤

Carrossel interativo de refrigerantes de fruta feito com HTML, CSS e JavaScript puro. Cada sabor tem sua própria cor de fundo, título e imagem, e dá para navegar entre eles com os botões de seta.

## Sabores

- 🍓 Morango
- 🥑 Abacate
- 🍊 Laranja

## Tecnologias

- HTML5
- CSS3 (variáveis CSS e animações com `@keyframes`)
- JavaScript (manipulação do DOM)

## Funcionalidades

- Navegação entre os slides com os botões anterior e próximo
- Navegação circular: do último volta para o primeiro e vice-versa
- Cor de fundo diferente para cada sabor
- Animação de entrada do título e da imagem da fruta a cada troca

## Estrutura do projeto

```
Refri-Dev/
├── assets/        # imagens dos refrigerantes e das frutas
├── index.html     # página principal
├── style.css      # estilos e animações
└── script.js      # lógica do carrossel
```

## Como usar

1. Clone o repositório:
```
   git clone https://github.com/FernandoFilhoDev/Refri-Dev.git
```
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.
